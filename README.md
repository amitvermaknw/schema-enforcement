# Schema Enforcement in Multi-Node Agent Graphs

Experimental code for the paper:
**"The Hidden Cost of Schema Enforcement: Validation-Repair Loops in Multi-Node Agent Graphs"**

## Quick start

```bash
# 1. Create and activate a virtual environment (Python 3.11+)
python3 -m venv .venv
source .venv/bin/activate         # macOS/Linux
# .venv\Scripts\activate          # Windows

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set up API keys
cp .env.example .env
# then edit .env and paste your keys

# 4. Run the pilot (5 samples, < $0.10)
python scripts/run_pilot.py

# 5. Inspect the SQLite log
sqlite3 results/experiments.db "SELECT * FROM runs;"
```

Or use the Makefile shortcuts:

```bash
make install    # creates venv + installs deps
make pilot      # runs the pilot
make clean-db   # wipes results/experiments.db
```

## Extending

- **Add a paradigm:** drop a new file in `src/schemaeval/paradigms/` implementing the
  same signature as `strict_repair.py`.
- **Add a topology:** drop a new file in `src/schemaeval/topologies/`. The node
  functions themselves stay identical; only the graph wiring changes.
- **Add a schema tier:** drop a new file in `src/schemaeval/schemas/`.
- **Add a model:** already parameterized — just pass the model name to the runner.

## Reproducibility

Every run is logged with model version, timestamp, and full metrics. The
`results/experiments.db` file is the authoritative record. To reproduce the
paper's figures:

```bash
python scripts/analyze.py --db results/experiments.db --out figures/
```
